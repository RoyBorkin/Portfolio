# Surface: portfolio (index.html + print.html)

Mode: Experience. Audience: hiring managers, tech leads, academic reviewers, clients. Job: see each product as an object, understand it in seconds, open details or the live app. Proof: real photographs, cut-outs, traced line drawings, real dimensions only where known, live apps. Constraint: almost no text.

## Direction contract
THESIS: Every project is a presentation board, the object first and every label pointing at a real part. Refuses the thumbnail-grid portfolio and the scrolling case-study essay.
OWN-WORLD: Studio-grey sweep (#E3E4E6 to #F2F2F3), off-black ink #17181A, graphite #55585E, white numerals and line drawings, one signal green #1E9E5A. Outfit 300/400/600/800. 1px inset frame, hairline leaders with small arrowheads, a white tag box top-right.
STORY: Cover board names Roy with his own photo annotated like a product; boards follow in order; Detail opens a sheet of figures and specs; the spec board is the CV.
FIRST VIEWPORT: Roy cut-out on the grey sweep, three leaders to real facts, his name set huge bottom-right, numeral 00, the version toggle in the tag box.
SIGNATURE: leaders and the traced outline draw themselves when a board arrives, like an engineer marking up a print.
RISKS: low-resolution cut-outs on retina; label accuracy needs owner review; dimensions only where real.
