# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS, no build step. Hosted on GitHub Pages as a new repo (royborkin.github.io/Portfolio); the existing royborkin.github.io site stays intact. PDF versions are generated from the same content via print layout (headless Chrome).

## Users

Hiring managers and design leads (industrial design roles), tech recruiters and dev leads (programmer roles), academic/research reviewers (PhD, grants, collaborators), and freelance clients. All scan fast; most decide in under a minute per project.

## Product Purpose

Roy Borkin's portfolio in two versions — Industrial Design and Programmer — each available as an interactive web app and as a PDF. Success: a viewer understands within seconds that Roy takes products from parametric model to working, manufactured object, and can drill into any project's images, video and live app.

## Positioning

A designer who builds the tools, the machines and the object: computational design + CNC/3D printing + shipped web apps, from IDF and a hardware startup to Technion research.

## Capabilities and Constraints

- Two tracks share one project dataset; each project belongs to one or both tracks.
- One visual style (the product presentation board), no style switcher.
- Owner will choose which projects to keep and their order after the first full pass — data must make reordering/hiding trivial.
- Minimal text: owner "doesn't believe in a lot of text". One-line project descriptions, facts as tags/labels.
